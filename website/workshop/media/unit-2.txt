单元 2：使用循环处理列表

时长：60 秒。无声原创代码演示，中文字幕已嵌入画面。
画面为脚本生成的代码工作台，不是浏览器点击操作录像。
所有代码均由真实本地 Tcl 解释器执行；标准输出与错误直接取自执行结果。
每个镜头都在新临时目录和新解释器中执行；教学文件随镜头预置。
源码只有显示折行，执行内容没有改变。文件操作不会访问私人数据。

[00:00:00.000–00:00:05.000] 一组测量，不逐条复制代码
这组读数里，负数表示采集失败；有效读数需要累计。
说明：原始数据：18、21、-1、19、23
代码：
set count 0
set total 0
foreach value {18 21 -1 19 23} {
    if {$value < 0} {continue}
    incr count
    set total [expr {$total + $value}]
}
puts "有效次数：$count"
puts "总和：$total"
真实 Tcl 9.0.4 标准输出：
有效次数：4
总和：81

[00:00:25.000–00:00:30.000] 有固定次数时使用 for
for 包含初始化、条件、更新、循环体四个参数。
代码：
for {set i 1} {$i <= 3} {incr i} {
    puts "测量 $i"
}
真实 Tcl 9.0.4 标准输出：
测量 1
测量 2
测量 3

[00:00:30.000–00:00:35.000] 检查计数的边界
把上界由 3 改成 2，输出也减少为两次。
代码：
for {set i 1} {$i <= 2} {incr i} {
    puts "测量 $i"
}
真实 Tcl 9.0.4 标准输出：
测量 1
测量 2

[00:00:35.000–00:00:40.000] while 每轮先检查条件
待处理数量在循环体中递减，保证最终能够结束。
代码：
set pending 3
while {$pending > 0} {
    puts "剩余：$pending"
    incr pending -1
}
foreach value {12 15 31 18} {
    if {$value > 30} {
        puts "首个异常：$value"
        break
    }
}
真实 Tcl 9.0.4 标准输出：
剩余：3
剩余：2
剩余：1
首个异常：31

[00:00:40.000–00:00:45.000] 找到首个异常就停止
