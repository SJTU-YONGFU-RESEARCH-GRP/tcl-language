[00:00:15.000–00:00:20.000] 逐行读取与空白行
gets 返回读取到的字符数；空白行长度 0 仍然是一行。
代码：
set ch [open notes.txt r]
set count 0
while {[gets $ch line] >= 0} {
    incr count
    puts "$count：[string length $line] 个字符"
}
close $ch
真实 Tcl 8.6.15 标准输出：
1：2 个字符
2：0 个字符
3：2 个字符
输入教学文件 notes.txt：
开始

结束

[00:00:25.000–00:00:30.000] 缺失文件产生真实错误
open missing.txt 失败，解释器返回原因；流程没有继续读取。
说明：当前目录没有 missing.txt。
代码：

puts [read $ch]
close $ch
真实 Tcl 8.6.15 标准输出：
（无标准输出）
真实解释器错误：
couldn't open "missing.txt": no such file or directory

[00:00:30.000–00:00:35.000] 用 catch 处理可预期问题
catch 返回错误状态，message 保存原因，再输出可理解的提示。
代码：
if {[catch {open missing.txt r} message]} {
    puts "无法读取文件"
    puts $message
}
真实 Tcl 8.6.15 标准输出：
无法读取文件
couldn't open "missing.txt": no such file or directory

[00:00:40.000–00:00:45.000] 生成一份摘要文件
读取三个值，统计数量与平均数，把结果写入 summary.txt。
代码：
set ch [open readings.txt r]
set values [split [string trim [read $ch]] "
"]
close $ch
set total 0.0
foreach value $values { set total [expr {$total + $value}] }
set count [llength $values]
set out [open summary.txt w]
puts $out "数量：$count"
puts $out [format "平均值：%.2f" [expr {$total / $count}]]
close $out
set check [open summary.txt r]
puts [string trim [read $check]]
close $check
真实 Tcl 8.6.15 标准输出：
数量：3
平均值：1.40
输入教学文件 readings.txt：
1.2
1.4
1.6
